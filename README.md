# Jogo da Velha (Tkinter)

Projeto educacional em Python com interface gráfica `tkinter`, dividido por versões:

## 📦 Versões

### 🔹 [Versão 1.0](./versao1.0/)
- Modo multiplayer local
- Interface visual com placar de vitórias
- Reinício de jogo sem reiniciar aplicação

### 🔸 [Versão 2.0](./versao2.0/)
- Tela inicial com seleção de modo de jogo
- Inclusão do modo contra IA
- Níveis de dificuldade: Fácil, Médio, Difícil
- Arquitetura modular para expansão

---

## ✅ Como executar

Entre na pasta da versão desejada e siga as instruções do `README.md` correspondente.
