# 🎮 Jogo da Velha - Versão 1.0

Esta é a **primeira versão funcional** do clássico jogo da velha (Tic Tac Toe) com interface gráfica feita em **Python + Tkinter**, totalmente em português.

---

## ✅ Funcionalidades

- 👥 Modo multiplayer local (2 jogadores no mesmo computador)
- 🎨 Interface com botões personalizados
- 📊 Placar de vitórias para X e O
- 🔁 Botão de reinício de partida (sem fechar o programa)
- 💬 Mensagens de vitória e empate

---

## 📁 Estrutura do Projeto

```
versao1.0/
├── app/
│   ├── interface.py        # Interface gráfica e lógica visual
│   └── logica_jogo.py      # Função que verifica se houve um vencedor
├── main.py                 # Inicia o jogo
└── README.md               # Este arquivo
```

---

## ▶️ Como executar

### 1. Clone o repositório e navegue até a versão 1.0

```bash
git clone https://github.com/seu-usuario/jogo-da-velha.git
cd jogo-da-velha/versao1.0
```

### 2. (Opcional) Crie um ambiente virtual

```bash
python -m venv venv
# Ative o ambiente virtual:
# Linux/macOS
source venv/bin/activate
# Windows
venv\Scripts\activate
```

### 3. Execute o jogo

```bash
python main.py
```
